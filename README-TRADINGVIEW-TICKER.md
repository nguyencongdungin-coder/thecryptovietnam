# TCV TradingView Ticker — bản mới

Thanh giá sử dụng TradingView Ticker Tape Web Component mới (`tv-ticker-tape`) với hướng hiển thị ngang, thay cho widget iframe cũ.

- Chèn dưới banner và phía trên Tổng quan thị trường.
- Dữ liệu và chuyển động phụ thuộc vào script TradingView, kết nối Internet và cài đặt giảm chuyển động của hệ điều hành/trình duyệt.
- TradingView có thể hiển thị giá trễ theo sàn và tài khoản; nguồn mã là danh sách cấu hình sẵn.
- Chạy thử với máy chủ HTTP (`py -m http.server 8000`) và mở `http://localhost:8000`.
- Kiểm tra trên trang chính thức https://www.tradingview.com/widget-docs/widgets/tickers/ticker-tape/ nếu vẫn đứng yên.
