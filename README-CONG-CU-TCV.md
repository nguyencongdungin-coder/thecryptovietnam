# Công cụ TCV – Phát triển bởi THE CRYPTO VIETNAM

Cập nhật nhận diện, không thay đổi thuật toán hay dữ liệu.

- Trang chủ (`index.html`): thay nhãn `Tiện ích` bằng `Công cụ TCV`; giữ dòng mô tả.
- Trang `tien-ich.html`: đổi tiêu đề trang thành `CÔNG CỤ TCV`, thêm dòng nhận diện. Giữ URL cũ để tránh hỏng liên kết.
- Các trang `ai-signal/index.html` và `market-radar/index.html`: thêm dòng nhận diện thương hiệu dưới tiêu đề.
- `style.css`: định dạng dòng nhận diện.

Không thay đổi TradingView, Market Pulse, dữ liệu, quy trình quét hay các liên kết công cụ.
