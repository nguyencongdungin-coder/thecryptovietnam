# THE CRYPTO VIETNAM — cập nhật tiêu đề trang chủ

- Giữ nguyên website phiên bản cũ đã chọn, logo, menu, AI Signal, Market Radar và các phần khác.
- Đổi tiêu đề hero thành **TÀI SẢN SỐ VIỆT NAM** trên một dòng trên máy tính, chữ “VIỆT NAM” màu vàng.
- Thay dòng mô tả dài bằng ba nhãn có dấu tích: Cập nhật nhanh / Phân tích chuyên sâu / Công cụ miễn phí.
- Giữ nguyên các nút hành động trước đó.
- Trên màn hình nhỏ tiêu đề được phép tự xuống dòng để không tràn ngang.

Mở index.html để xem bố cục, hoặc chạy `py -m http.server 8000` tại thư mục này để thử nghiệm tính năng tải dữ liệu.
